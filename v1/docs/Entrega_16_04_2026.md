## 8. Previsualización de adjuntos en el chat (`v1/assets/js/widget/chat.js` + `v1/assets/css/widget/chat.css` + `v1/views/widget/chat.hbs`)

Se reemplazó la función `normalizarLinksAdjuntos(elemento)` por una versión enriquecida que, además de normalizar URLs y garantizar `target="_blank"`, detecta la extensión del archivo adjunto y reemplaza el `<a>` plano por una **tarjeta de previsualización**. Los íconos de tipo de archivo usan **Font Awesome** cargado localmente desde `v1/assets/fonts/fontawesome/`.

### Carga de Font Awesome (`chat.hbs`)

Se agregó el `<link>` a Font Awesome local en el `<head>` del template, evitando dependencia de CDN externo:

```html
<link rel="stylesheet" type="text/css" href="/fonts/fontawesome/css/all.min.css">
```

### Comportamiento por tipo de archivo

- **Imágenes** (`jpg`, `jpeg`, `png`, `gif`, `webp`): miniatura de 220×140 px (`<img loading="lazy">`). Clic en la miniatura abre un **lightbox Swal2** con la imagen a pantalla completa y botón _"Abrir en nueva pestaña"_. El nombre del archivo debajo es un link que también abre en nueva pestaña.
- **PDF**: tarjeta vertical con ícono `fas fa-file-pdf` (rojo `#e74c3c`) a 3.5 rem.
- **Word** (`doc`/`docx`): tarjeta vertical con ícono `fas fa-file-word` (azul `#2b579a`).
- **Excel** (`xls`/`xlsx`): tarjeta vertical con ícono `fas fa-file-excel` (verde `#217346`).

### Layout de tarjetas de archivo (PDF / Word / Excel)

Las tarjetas de documento usan **layout vertical centrado**: ícono grande arriba, nombre del archivo abajo como link clickeable. No hay botón separado — el **nombre del archivo es el enlace de acción** (`Abrir` o `Descargar` según el tipo), con hover que lo subraya y cambia el color a `#2c1763`. La tarjeta completa tiene efecto hover (`translateY(-2px)` + sombra) para orientar visualmente al usuario.

### Funciones en `chat.js`

- `_adjuntoTarjetaImagen(href, nombre)` — tarjeta de imagen con miniatura y nombre-link
- `_adjuntoTarjetaArchivo(href, nombre, tipo)` — tarjeta vertical para PDF / Word / Excel
- `_adjuntoLightbox(url, nombre)` — lightbox Swal2 con imagen a pantalla completa

Los tres puntos de llamada (`listarMensajeNoLeido`, `listarConversacion`, `listarConversacionCompleta`) no requirieron cambios pues siguen invocando `normalizarLinksAdjuntos()`.

## 7. Estilo de enlaces — color de marca y cursor pointer (`v1/assets/css/widget/chat.css`)

Se actualizaron todos los estilos de enlaces (`<a>`) en el widget. El color final de los links es `#372564` (púrpura de marca) con hover `#2c1763`:

- **Variables CSS** (`--color-link` y `--color-link-hover`): `#372564` y `#2c1763` respectivamente.
- **Selector `a`**: color via variable, `cursor: pointer` explícito.
- **Selector `a:hover`**: color hover via variable, `text-decoration: underline`, `cursor: pointer`.
- **`.form-link`**: color `#372564 !important`; hover `#2c1763 !important` con subrayado.
- **Corrección de regla problemática**: el selector `.modal-body, p, a { color: #000000 !important }` pisaba el color de **todos** los enlaces de la página. Se separó en:
  - `.modal-body, .modal-body p` → texto negro (solo dentro del modal)
  - `.modal-body a` → `#372564 !important` con cursor pointer
  - `.modal-body a:hover` → `#2c1763 !important` con subrayado

> **Nota:** el color de links fue inicialmente definido como `#0021f5` y posteriormente ajustado a `#372564` para mantener coherencia con la paleta de la marca (mismo color del botón principal `--button-primary-bg`).

## 6. Horario de atención vía variables de entorno en el controlador (`v1/controllers/widget/chat.controller.js`)

Se refactorizó `estaEnHorario()` para leer el rango de atención desde el `.env` en lugar de tenerlo hardcodeado:

```env
HORARIO_ATENCION_INICIO=07:00
HORARIO_ATENCION_FIN=16:30
```

Si las variables no están definidas se usan los valores anteriores como fallback. La comparación se realiza en minutos totales (mismo criterio que el cliente). Esto centraliza el control del horario en un único lugar (.env), aplicable tanto al servidor como al widget.
